时间复杂度

“遍历几次"只是直观类比，本质是"操作次数随 n 如何增长”

大 O 描述的是操作次数随输入规模 n 的增长趋势，忽略常数和低阶项。

复杂度 含义 典型例子
O(1) 常数，与 n 无关 数组按索引访问、哈希表查找（平均）
O(log n) 每步规模减半 二分查找
O(n) 与 n 成正比 遍历数组一次
O(n log n) n 乘以 log n 归并排序、快速排序（平均）
O(n²) 与 n² 成正比 双重循环、冒泡排序
O(2ⁿ) 指数增长 暴力枚举子集

注意 O(log n)：它不是遍历 n 次，而是遍历 log₂n 次左右。比如 n=1024 时只走约 10 步。所以"括号里是什么就是遍历几次"这个说法对 O(n) 成立，对 O(log n)、O(n²) 就不准确了。

怎么计算时间复杂度（实操步骤）

  1. 找基本操作：哪一行是执行最频繁的核心操作。
  2. 数它执行了多少次（用 n 表示）。
  3. 只保留最高阶项，去掉常数系数。

def example(arr):
    n = len(arr)
    total = 0
    for x in arr:          # 执行 n 次
        total += x
    for i in range(n):     # 外层 n 次
        for j in range(n): # 内层 n 次 → 共 n² 次
            total += i * j
    return total

总次数 ≈ n + n²，去掉低阶项 n，去掉系数，得到 O(n²)。

几个常见规则：

  • 顺序结构相加：O(n) + O(n²) → O(n²)（取大的）
  • 嵌套循环相乘：外层 n 次 × 内层 n 次 = O(n²)
  • 循环变量每次减半：O(log n)
